## Technologies used

## HTML

Some of the main tags and concepts we used to develop this project were:

- **`<!DOCTYPE html>`** declares the document type as HTML5.  
- **`<html>`** is the root tag that contains all page content.  
- **`<head>`** contains header information such as the page title, character set, and links to styles and external fonts.  
- **`<meta charset="UTF-8">`** sets the character encoding to UTF-8.  
- **`<title>`** defines the page title shown in the browser tab.  
- **`<link>`** imports external style files and web fonts.  
- **`<body>`** contains all visible page content such as text, images, and interactive elements.  
- **`<nav>`** defines a navigation section such as a navigation menu.  
- **`<div>`** is a generic container used to group elements and build layouts.  
- **`<h2>`** defines a second-level heading.  
- **`<p>`** defines a paragraph of text.  
- **`<i>`** defines italicized text.  
- **`<hr>`** defines a horizontal rule.  
- **`<b>`** defines bold text.  
- **`id`** assigns a unique identifier to an element.  
- **`<br>`** inserts a line break.  
- **`<span>`** marks a small inline text fragment.  
- **`fa`** is the Font Awesome icon class.  
- **`w3`** is the W3CSS style class.  
- **`style.css`** is the external CSS file name.  
- **`<footer>`** defines the page footer section.

## CSS

- **`w3-twothird`** sets an element to two thirds of the parent container width.  
- **`w3-container`** defines a centered container with a maximum width.  
- **`w3-center`** centers content horizontally inside an element.  
- **`w3-card`** creates a card-like element with a shadow.  
- **`fa`** applies styles to Font Awesome icons.

### CSS properties used in the example

- **`color`** sets text color.  
- **`background-color`** sets element background color.  
- **`font-size`** sets font size.  
- **`padding`** sets internal spacing.  
- **`margin`** sets external spacing.  
- **`text-align`** sets horizontal text alignment.  
- **`box-shadow`** creates a shadow around an element.  
- **`display`** sets the element display type such as `block`, `inline`, or `flex`.  
- **`border-radius`** sets corner rounding.

### Other CSS concepts

- **ID and Class Selectors** The ID selector uses `#` followed by the element ID. The class selector uses `.` followed by the class name.  
- **Font Awesome** is a vector icon library customizable with CSS and commonly used to add icons to websites and web apps.  
- **Box model** defines how an element is rendered and is composed of content, padding, border, and margin.  
- **Responsiveness** is the ability of a site to adapt to different screen sizes and devices. The class **`.w3-twothird`** is used to set an element width to two thirds of the parent container to help responsiveness.

## CI CD

CI and CD are essential practices in software development that aim to streamline and accelerate the delivery of quality software.

**Continuous Integration (CI)** is a process where developers frequently integrate their code into a shared repository so automated tests run on each integration. This helps ensure the code works correctly and prevents conflicts with other parts of the system.

**Continuous Delivery (CD)** automates the delivery of software to production once the code passes all required tests. This enables rapid and reliable deployment of changes.

In summary, CI and CD improve software quality and speed up delivery, making the process more reliable and efficient.

## GitHub Pages

GitHub Pages is a static site hosting service provided by GitHub. It allows you to create a static website using HTML, CSS, and JavaScript and host it directly from a GitHub repository.

GitHub Pages is commonly used to host project documentation, personal sites, blogs, and portfolios. It is easy to set up and free to use with options to customize the site domain and apply predefined themes for quick, attractive site creation.

GitHub Pages also supports Jekyll, a static site generator that simplifies building more complex sites by providing automatic page generation and layout features.
